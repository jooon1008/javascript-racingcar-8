# 구현할 기능

- 경주할 자동차 이름을 문자열로 입력받고 쉼표(`,`)를 기준으로 구분한다.
  - `InputView` 클래스로 자동차 이름 입력을 담당한다.
  - `CarFactory` 클래스로 입력받은 이름을 `Car` 객체 배열로 변환한다.
- 시도할 횟수를 입력받고 숫자로 변환한다.
  - `InputView` 클래스로 시도 횟수 입력을 담당한다.
- 자동차 이름과 전진 거리를 관리하는 `Car` 클래스를 구현한다.
  - 생성자를 통해 자동차 이름과 초기 전진 거리 `0`을 설정한다.
  - 자동차를 한 칸 전진시키는 메서드를 구현한다.
- `0`부터 `9` 사이의 무작위 값을 생성해 자동차의 전진 여부를 결정한다.
  - 무작위 값이 `4` 이상인 경우에만 자동차를 전진시킨다.
  - `Race` 클래스에서 라운드별 경주 진행을 담당한다.
- 입력받은 시도 횟수만큼 경주를 진행한다.
  - `App`에서 전체 경주 흐름을 제어한다.
  - `Race`에서 자동차별 전진 여부와 라운드 진행을 담당한다.
- 매 라운드가 끝날 때 자동차 이름과 전진 거리를 출력한다.
  - 전진 거리는 `-` 문자로 표시한다.
  - `OutputView` 클래스로 경주 결과 출력을 담당한다.
- 가장 멀리 전진한 자동차를 최종 우승자로 선정한다.
  - `Race` 클래스에서 최종 우승자를 판별한다.
  - `OutputView` 클래스에서 최종 우승자를 출력한다.
- 공동 우승자가 있는 경우 우승자 이름을 쉼표(`,`)로 구분해 출력한다.

# 예외 처리

## 자동차 이름 입력

- 자동차 이름이 비어 있는 경우
  - 예시: `""`, `pobi,,woni`
- 자동차 이름에 공백이 포함된 경우
  - 예시: `pobi, woni`
- 자동차 이름이 5자를 초과하는 경우
  - 예시: `abcdef,pobi`
- 쉼표로 시작하거나 끝나는 경우
  - 예시: `,pobi,woni`, `pobi,woni,`

## 시도 횟수 입력

- 양의 정수가 아닌 값을 입력하는 경우
  - 예시: `0`, `-1`, `1.5`
- 숫자가 아닌 값을 입력하는 경우
  - 예시: `a`, `@`, `3회`

- 잘못된 입력이 들어오면 `[ERROR]`로 시작하는 메시지와 함께 `Error`를 발생시킨다.
