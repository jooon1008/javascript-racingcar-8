# javascript-racingcar-precourse
# 자동차 경주

## 구현할 기능 목록

### 1. 자동차 이름 입력
- [ ] `Console.readLineAsync()`를 사용해 자동차 이름 문자열을 입력받는다.
- [ ] 쉼표(`,`)를 기준으로 자동차 이름을 분리한다.
- [ ] 분리된 자동차 이름 목록을 저장한다.

### 2. 자동차 이름 검증
- [ ] 이름엔 공백, 빈 문자열이 올 수 없다.
- [ ] 5글자 이하여야한다.

### 3. 이동 횟수 입력
- [ ] `Console.readLineAsync()`를 사용해 이동 횟수를 입력받는다.
- [ ] 입력된 이동 횟수를 숫자로 변환한다.

### 4. 이동 횟수 검증
- [ ] 이동횟수엔 양수만 입력 받을 수 있다.

### 5. 자동차 상태 생성
- [ ] 각 자동차가 자신의 이름과 현재 이동 거리를 가지도록 상태를 구성한다.
- [ ] 모든 자동차의 초기 이동 거리를 `0`으로 설정한다.

### 6. 자동차 전진 여부 결정
- [ ] `MissionUtils.Random.pickNumberInRange(0, 9)`를 사용해 무작위 값을 생성한다.
- [ ] 생성된 값이 `4` 이상이면 자동차를 한 칸 전진시킨다.
- [ ] 생성된 값이 `4` 미만이면 자동차를 이동시키지 않는다.

### 7. 한 라운드 경주 진행
- [ ] 모든 자동차를 한 번씩 순회한다.
- [ ] 각 자동차의 전진 여부를 독립적으로 결정한다.
- [ ] 전진한 자동차의 이동 거리를 증가시킨다.

### 8. 전체 경주 진행
- [ ] 입력받은 이동 횟수만큼 라운드를 반복한다.
- [ ] 매 라운드가 끝날 때 현재 자동차들의 이동 상태를 출력한다.

### 9. 경주 진행 상황 출력
- [ ] 자동차 이름과 이동 거리를 함께 출력한다.
- [ ] 이동 거리는 `-` 문자의 개수로 표현한다.
- [ ] 모든 자동차의 상태를 지정된 출력 형식에 맞게 출력한다.

### 10. 우승자 판별
- [ ] 모든 자동차 중 가장 큰 이동 거리를 구한다.
- [ ] 가장 큰 이동 거리와 같은 자동차를 모두 우승자로 선택한다.
- [ ] 공동 우승자가 발생할 수 있도록 처리한다.

### 11. 최종 우승자 출력
- [ ] 우승자가 한 명인 경우 해당 자동차 이름을 출력한다.
- [ ] 우승자가 여러 명인 경우 쉼표(`,`)로 연결해 출력한다.
- [ ] 지정된 최종 우승자 출력 형식을 지킨다.

## 예외 처리 목록

### 자동차 이름 관련
- [ ] 자동차 이름 입력이 빈 문자열인 경우
- [ ] 자동차 이름이 5자를 초과하는 경우
- [ ] 이름에 공백이 들어올 경우
- [ ] 자동차 이름 사이에 빈 값이 존재하는 경우
  - 예: `pobi,,woni`
- [ ] 자동차 이름 문자열이 쉼표로 시작하는 경우
  - 예: `,pobi,woni`
- [ ] 자동차 이름 문자열이 쉼표로 끝나는 경우
  - 예: `pobi,woni,`
- [ ] 이름 없이 쉼표만 입력된 경우
  - 예: `,`
- [ ] 여러 개의 쉼표만 입력된 경우
  - 예: `,,,`

### 이동 횟수 관련
- [ ] 이동 횟수 입력이 빈 문자열인 경우
- [ ] 숫자가 아닌 값을 입력한 경우
  - 예: `abc`
- [ ] 숫자와 문자가 섞인 경우
  - 예: `3회`, `3a`
- [ ] 음수를 입력한 경우
  - 예: `-3`
- [ ] 소수를 입력한 경우
  - 예: `3.5`
- [ ] `0`을 입력한 경우를 허용할지 요구사항에 맞게 검증한다.
- [ ] 공백만 입력한 경우
- [ ] 숫자 앞뒤에 불필요한 공백이 있는 경우를 요구사항에 맞게 검증한다.

### 공통 예외 처리
- [ ] 모든 잘못된 입력은 `[ERROR]`로 시작하는 메시지를 가진 `Error`를 발생시킨다.
- [ ] `process.exit()`를 사용하지 않는다.
- [ ] 예외가 발생한 이후 경주 로직이나 출력 로직이 계속 실행되지 않도록 한다.
